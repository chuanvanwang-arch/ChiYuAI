线索发现 · 拓客规则

本页回答两个问题：线索从哪来、什么线索值得要。 你可以在这里设定目标客户画像（行业 / 规模 / 地区）、选择数据来源、调整信号关注度、配置去重规则——全部在后台调整，无需改代码。 任一付费数据源默认关闭，需显式授权并填写密钥后才会启用；所有保存都会生成审批凭证（写操作经系统审批闸门）。
主动拓客（对话驱动）
除了被动接收融资 / 招聘 / 中标等外部信号，你还可以在 MCP 对话里主动拓客： 对销售助手说「找 50 人以上、年营收 1 亿以上的医疗企业」，助手会按下方「目标客户画像」与「信号权重」批量搜索候选企业， 你圈选确认后一键进入公海池（S0）。所用规则与上方配置一致；付费数据源同样默认关闭，需授权后才参与搜索。 （对应模块设计：docs/2026-09-14-prospecting-module-design.md，前端入口为后续迭代）
目标客户画像（ICP）
定义「什么样的企业是你的目标客户」。线索发现与主动拓客（对话内）都会按这组条件筛选候选。
数据来源
从哪些渠道获取线索。系统级数据源（邮箱验证 / 网页检索 / 标讯 / 地理画像）出厂即可用；付费数据源默认关闭，需在「外部数据接入」页授权后启用。
数据源类型适用范围成本档启用
关注信号与权重（0–1）
哪些企业动态更能说明「对方正处在有购买需求的窗口期」。权重越高，命中该信号的企业排序越靠前。

「招聘 / 新战略」类外部情报本平台暂无可信数据源（已标注 无内部数据源，不计入筛选）； 内部可观测的客户异动（联系人台账变动、关系冷却）以 内部推断 标注，权重低于实测情报。

去重规则（按顺序逐组比对）
避免同一家企业重复入池。比对按顺序执行：先按第 1 组条件，都命中即视为重复；否则尝试第 2 组，以此类推。同一组内多个字段需全部命中才算重复。
例：[["external_id"],["domain"],["name"]] —— 先按外部 ID 比，再按域名，最后按名称。
自动处理策略（Playbooks）
为特定客户群编写「命中后如何处理」的策略：自动收窄数据来源、挂接智能体处理。出厂不预置（显示 [] 属正常，非故障）；行业模板在租户开户时按行业播种（db/seed/discovery-rules-templates.js）。 每行一项策略；名称必填（空将被拒绝保存）；命中信号填信号类型，多个用 && 同时命中（如 tender_match&&funding_round，留空或以 default 命名作兜底）；数据源/AI研究/动作为数组，单元格内逗号分隔（如 tender,gaode）。

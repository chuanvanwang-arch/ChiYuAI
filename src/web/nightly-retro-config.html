夜间批量复盘配置

夜批复盘智能体每日全量扫描决策、结合 LLM 深度归因为整改报告 + ADMIN 待办（§16.3）。本页控制复盘阈值，数据存入 config_store['decision-retro']，写操作经决策第0闸 + sysadmin 权限（系统级配置，仅 ADMIN/sysadmin 可变更）。阈值全部后台可配，代码零硬编码。复盘真实产出可在 「智能体工作台」 查看。
样本与窗口
低于此值的簇样本不足 → 不出处方（真实日产量个位数时可下调，或开扩窗）
24h 全簇样本不足时自动扩展到下方窗口
默认 168h（7d），避免长链路无限回溯
LLM 调用护栏
DeepSeek-V4-Flash 为推理模型，单次 106~125s，禁 20s
超期剩余簇降级（R5 deadline）
LLM 连续不可信达此数 → 熔断后续簇（R5）
生效说明（只读）
环节行为
样本门槛簇 count < min_sample 即短路（不出处方、不调 LLM），仅启发式洞察
窗口自适应24h 全簇不足且扩窗开启 → 扩至 window_extend_hours 重取，报告标 window_extended
超时单簇 LLM 调用超 llm_timeout_ms → 降级（禁裸 catch，emit trace 留痕）
总预算累计耗时超 total_deadline_ms → 剩余簇强制降级（deadline_hit 标记）
熔断真实调用 LLM 且连续不可信达 llm_fail_circuit → circuit_open，后续簇跳过（样本不足短路不计入）
失败策略配置读失败按出厂默认执行；任一异常不影响决策本身落库
出厂默认：min_sample=20 · 扩窗开 · 168h · 超时 180s · 预算 600s · 熔断 3。

① 选一条接入路径

② 验证与说明

        
验证方式按路径分路（三条路各自 fail-closed，互不冒充）：
          C 平台直连 → 平台侧 verifyScope 真实探测（探测不通过即不接入，绝不用 mock 代真；
          凭据不全 → credentials_incomplete 并列出缺哪个字段，连不通 → connect_failed，账号/密码错 → auth_failed）；
          A 连接器 / B 本机桥 → 平台拿不到你的凭据，因此无法代验：接入后状态为「待确认」，
          须由你在自己那侧确认（连接器：让我读取一次日程/邮件；本机桥：在本机跑通自检命令）。
          三种情况都不会被显示成「已验证」。

事件触发复盘配置

重大决策确认（CONFIRMED）后，系统自动为复盘智能体建一条复盘待办，无需人工发起。本页控制触发条件，数据存入 config_store['event-retro']，写操作经决策第0闸 + sysadmin 权限。复盘产出可在 「智能体工作台」 查看。全部阈值后台可配，代码零硬编码。
触发条件
生效说明（只读）
环节行为
触发信号决策被人工确认（HITL 确认 → 状态 CONFIRMED）
分级判定取决策自身业务分级（NORMAL < HIGH < CRITICAL），低于上面所选下限则不触发
去重同租户在冷却窗内已有复盘待办（含人工发起的）则跳过，避免复盘刷单
执行方复盘智能体（决策复盘 + 整改处方），待办不再走评审闸门
失败策略配置读失败按出厂默认执行；触发环节任何异常都不影响决策本身落库
出厂默认：启用 · HIGH 起触发 · 24 小时冷却 · 建单后立即派发。

# method-stage-progression · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）用阶段推进法看团队管线分布与卡点。

## 使用心态

- 我看的不是单条商机，是**阶段分布与卡点**——几条在 S1/S2（早期），几条卡在 S3/S4（商务/条款），几条在 S5/S6（履约）。
- 卡在 S3/S4 且超期的商机 = 该止损或该补证，别让团队空耗。

## 视角差异

- 看「阶段分布」：按 S1-S6 分组计数，早期（S1/S2）占比是否健康，中段（S3/S4）是否有堆积。
- 看「卡点判定」：S3/S4 停留超 `sales-thresholds.stage.stuck_days`（出厂建议 30）天 → 推进卡点（§12.3bis）；S2 之后无 SWAS 的商机 → 不可推进商机。
- 看「输单信号」：团队商机里有多少已触发输单条件但还没止损的 → 周会点名处理。

## 输出形态（口语化但机器可读）

```
管线分布（16 条）：S1×4 / S2×4 / S3×5 / S4×2 / S5×1 / S6×0
卡点：S3×3 停留超 `sales-thresholds.stage.stuck_days`（出厂建议 30）天（商务条款卡点，补 BANTCC 或止损）；S2×1 无 SWAS（不可推进）
输单信号：2 条已触发输单条件未止损 → 本周处理
```

## 红线

- 不把「阶段停留」当「商机停滞」——先判客户行为（客户可能在内部审批，阶段推进慢但正常）。
- 卡点判定必须看数据（停留时长/SWAS 完整性），不凭主观印象。

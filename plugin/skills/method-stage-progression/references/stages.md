# method-stage-progression · S1-S6 释义与 溯源（references/stages.md）

## 阶段释义

| 阶段 | 含义 | 客户行为特征 | 输单条件 |
|---|---|---|---|
| S1 | 线索发掘（客户评估需求） | 客户在寻找供应商/评估需求（约见/要资料/现场交流） | 无可跟进线索/需求不成立 → 止损 |
| S2 | 需求确认（客户明确痛点） | 客户在明确需求与痛点 | 需求不成立/无预算 → 止损 |
| S3 | 方案匹配（客户评估匹配度） | 客户在评估方案匹配度 | 方案不匹配/被竞品替代 → 止损 |
| S4 | 报价谈判（客户评估商务条款） | 客户在评估商务条款与报价 | 价格谈不拢/商务条款不认可 → 止损 |
| S5 | 合同确认（内部审批） | 客户在合同签署内部审批 | 合同条款未达成一致 → 止损 |
| S6 | 赢单移交（终态） | 客户完成验收付款并移交项目 | — |

# method-opportunity-matrix · 维度释义（references/dimensions.md）

## V1 · 商业价值（Business Value）

- 商机金额量级（`payload.expected_amount`）？战略意义（进入新行业/标杆客户）？
- 可复制性：赢下该商机后能否复制到相似客户（参考 `payload.replicable`）？
- 反例：金额大但一次性、无战略意义 → 价值未必高。

## F1 · 可行性（Feasibility）

- 决策链是否打通（对齐 MEDDICC E1/D2：经济买家触达、流程节点清晰）？
- 预算是否确认（对齐 BANT B：预算号/预算线）？
- 产品匹配度：方案能否覆盖客户硬需求（无硬伤）？

## P1 · 竞争定位（Competitive Position）

- 相对竞品：领先 / 并列 / 落后？
- 是否有差异化证据（POC 通过、参考案例、独特能力）？

## 与其它方法论衔接

- V1×F1 的可行性判据直接引用 BANT（B/A/N）与 MEDDICC（E1/D1/D2/I1）的评分证据——机会矩阵不重复采集，复用该两方法论的输出。

# method-meddicc · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）用 MEDDICC 看复杂商机池（大金额/长周期）的赢单概率分布，决定资源投哪。

## 使用时的心态

- 我看的不是单条大单，是**复杂商机池的概率分布**——哪几条真有机会、哪几条还在"讲故事"阶段。
- MEDDICC 是资源倾斜依据：把最强教练/售前资源投给 E/D/I/C 四维齐备的单子。

## 视角差异

- 看「概率梯队」：池子里几条 ready≥0.8（主攻，配售前）、几条 0.6–0.8（需补决策链）、几条 <0.6（暂缓或放弃）。
- 看「缺口模式」：普遍缺 E1（经济买家未触达）→ 销售层级要上提；普遍缺 D2（流程不清）→ 教练销售流程技巧。

## 输出形态（口语化但机器可读）

```
复杂商机池：5 条 → ready≥0.8 有 1 条（主攻+售前资源）/ 0.6-0.8 有 3 条（本周补决策链）/ <0.6 有 1 条（暂缓）
缺口模式：3/5 缺经济买家触达（E1）→ 本月重点：把对接层级上提至预算审批人
```

## 红线

- 不得把「暂缓」误读为「放弃」——<0.6 是补证期，不是丢单。
- 资源投入优先级：ready≥0.8 复杂商机第一梯度；0.6-0.8 用于补决策链训练。

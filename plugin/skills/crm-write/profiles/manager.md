# crm-write · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）用 crm-write 做「组合级写动作」——批量推进/报价/输单原因确认。

## 高频对话

- 「把这几条商机一起推到报价」→ 多商机 crm-deal-advance（只进不退）
- 「这批报价一起提交审批」→ crm-approval-start 批量
- 「这条输单原因填了没？」→ 输单必填原因纪律检查

## 写纪律（经理视角）

- 批量写也要逐条带 decision_id（第0闸按条卡）。
- 输单（lost）必须填 reason——「原因缺失 = 写被拒」不是建议。
- 经理可批量但不可绕过两阶段：每条 phase1→phase2。

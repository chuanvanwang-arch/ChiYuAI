# method-fact-vs-script · 销售视角（profiles/sales.md）

> 视角：销售（sales）用事实vs话术判断「客户说的哪些能当真、哪些要先验证」。

## 使用时的心态

- 我不是在挑客户话里的毛病，是在**保护自己的判断**——把口头承诺当真，最后丢单的是我。
- 事实/话术分类是跟进清单生成器：每句话术 = 一个待办验证动作。

## 视角差异

- 我看的不是"客户说了什么"，是"**哪句能进商机 payload 当证据，哪句要标成待验证**"。
- 口头意向 → 立即对应验证动作：要预算号（B）、约决策人（A/E1）、POC 排期（D2）、要选型标准（D1）。

## 输出形态（口语化但机器可读）

```
事实vs话术：F=预算号已发邮件✅(E0.9) / S="领导很支持"⚠️(需约见佐证) / S="我们很急"⚠️(需时间窗)
gate=NEEDS_VERIFICATION → 下一动作：约采购 VP 验证领导支持度与上线时间
```

## 红线

- 无事实支撑（E<0.8）的关键维度禁止乐观推进——这是规则不是建议。
- 话术必须转成验证动作，不得当证据直接入库支撑推进。

# method-funnel-classification · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）用大漏斗看团队客户分类分布与覆盖缺口。

## 使用心态

- 我看的不是单个客户分类，是**团队客户池的结构**——商机/目标/潜力各占多少，覆盖节奏有没有人掉队。
- 分类分布揭示资源错配：目标客户太多没商机 → 识别能力不足；潜力客户被高频拜访 → 时间浪费。

## 视角差异

- 看「分类分布」：团队客户按商机/目标/潜力分组计数，占比是否与市场预期相符。
- 看「覆盖缺口」：目标客户近 `sales-thresholds.coverage.target_month_days`（出厂建议 30）天未拜访名单、潜力客户近 `sales-thresholds.coverage.potential_quarter_days`（出厂建议 90）天未接触名单（§12.3bis 达标判定）。
- 看「商机过滤缺口」：有需求客户但没建商机的（BH-02-02）→ 点名销售补建。

## 输出形态（口语化但机器可读）

```
团队客户池（180 家）：商机×30 / 目标×80 / 潜力×70
覆盖缺口：目标 80 家里 25 家近30天未拜访（覆盖率 69%）；潜力 70 家里 18 家近90天未接触
商机过滤缺口：6 家已有需求未建商机 → 本周跟销售逐一确认
```

## 红线

- 覆盖缺口名单 = 管理抓手，不是责备清单（先看销售是否忙于商机推进，再谈节奏）。
- 分类是动态的（客户行动变化 → 分类变化），每季度至少复核一次团队分类分布。

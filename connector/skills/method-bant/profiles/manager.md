# method-bant · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）用 BANT 看团队商机池的资质分布，决定资源往哪投。

## 使用时的心态

- 我看的不是单条商机，是**池子的资质分布**——几个 BANT 四维齐备的单子值得全力投入，几个缺预算/缺决策人的单子先让销售去补证。
- BANT 是**投入分配依据**，不是打击销售积极性的工具。

## 视角差异

- 看「就绪度分布」：团队 10 条商机里几条 ready≥0.8（可冲）、几条 0.6–0.8（需补证）、几条 <0.6（暂缓）。
- 看「缺口模式」：普遍缺 B（预算）→ 调整报价/客群定位；普遍缺 A（决策人权）→ 销售触达层级要上提。

## 输出形态（口语化但机器可读）

```
团队商机池：12 条 → ready≥0.8 有 3 条（主攻）/ 0.6-0.8 有 5 条（本周补证）/ <0.6 有 4 条（暂缓）
缺口模式：7/12 缺决策人权（A）→ 本月重点：销售触达层级上提至 CEO/VP
```

## 红线

- 不得把「暂缓」误读为「放弃」——<0.6 是补证期，不是丢单。
- 资源投入优先级：ready≥0.8 商机第一梯度；0.6-0.8 商机用于训练补证能力。

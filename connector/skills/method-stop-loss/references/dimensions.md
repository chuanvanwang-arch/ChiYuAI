# method-stop-loss · 维度释义（references/dimensions.md）

## NV · 净投入净值（Net Value）

- 累计投入成本：人力（销售/售前人天）、时间（跟进周期）、资源（DEMO/POC 制作）。
- 赢单预期收益现值：`expected_amount × win_probability`（概率参考 MEDDICC 赢单把握）。
- 净值 = 预期收益现值 − 已投入；净值转负 = 继续投入在经济学上已不成立。
- 反例：只看投入不看预期收益 → 把"跟了很久"当"快成了"，是沉没成本谬误的典型形态。

## CB · 投入预算上限（Cost Budget）

- 商机启动时必须预设：最多投入多少人天/金额/周期（写进商机评审纪要）。
- 未预设上限 = 无限投入风险——止损的前提是"知道投了多少是头"。
- 预算上限要与商机金额成比例（如 ≤ 预期收益的 20%），避免大单烧掉过多售前资源。

## EG · 退出门（Exit Gate）

- 明确的退出信号清单（写入商机评审纪要）：
  - 预算超支（使用率 > 100%）
  - 关键里程碑连续未达成（如两次 POC 推迟）
  - 关键决策人离职/换岗（决策链断裂且无法重启）
  - 客户信用恶化（逾期/裁员/业务收缩）
- 退出门的价值：**决策在投入前已定，不需要在亏损时情绪化拍板**（前置设定优先）。

## 与其它方法论衔接

- 与 `method-risk-tradeoff` 互补：风险权衡回答"要不要进"，止损点回答"何时撤"。
- win_probability 引用 MEDDICC 输出；投入上限的预算判断引用 BANT 的 B（预算）维度可覆盖性。

# 项目简介：企业AI销售决策平台（CRM-AI-Native）

（品牌 ChiYu AI；主体：北京青羽智行科技有限公司；全文约 900 字，用于申报/评审材料）

## 一、项目主要内容
本项目自主研发一款以智能体为核心的企业AI销售决策平台，覆盖线索获取、商机推进、报价审批、合同回款全流程，采用"粒子—事件—智能体—门户"四平面架构：以 PostgreSQL+pgvector 为数据底座，读默认直连、写显式过闸；SSE 事件总线驱动写时向量构建、记忆捕获、预警审计与反馈闭环；多智能体编排引擎承担跟进提醒、客户洞察、决策预判；以 MCP 协议标准化对接外部系统；多租户加行业配置化，适配制造、医疗器械、化工、汽车等 B2B 行业。

## 二、解决的业务痛点
1. **决策不可复现、不可审计**：传统模式下商机判断靠个人直觉，依据无从追溯。平台以"确定性评分+生成式模型"混合裁决并全量落库，形成可审计决策链。
2. **软建议易越过业务硬约束**：以"红线先于置信度"硬规则判定，命中红线强制转入人工审批，杜绝超权限报价、私下承诺等违规行为，守住利润与合规底线。
3. **销售过程黑洞**：线索散落、跟进靠记忆、过程不可见。平台将线索公海、跟进记录、客户 360 洞察、回款对账全链路数据化，过程实时可监控。
4. **知识经验难沉淀**：谈单经验、客户先例存于个人脑内，人走经验走。平台以双轨记忆系统将对话、决策、先例蒸馏归档，形成组织级记忆资产。

## 三、预计效果
销售流程全链路数字化与合规化：决策全程可审计、审批全程留痕、超权限报价自动拦截；线索转化与回款对账实时可监控；AI 承担信息检索、跟进提醒、决策预判等辅助工作，人工复核聚焦高价值环节，销售聚焦客户沟通、效率显著提升；销售方法论以技能包沉淀复用，新人培养周期缩短、团队扩张不依赖个别明星销售。

## 四、创新性
1. **混合决策引擎**：确定性评分与生成式模型结合，兼具可复现性与语义理解能力，红线优先保障治理（已申请发明专利）。
2. **双轨记忆系统**：智能体运行时记忆分层与七维校验，记忆可写入、可蒸馏、可审计（已申请发明专利）。
3. **四平面架构**：10 大 AI 原生能力各有明确挂点，能力不堆叠、不缺失。
4. **受控门户生成**：NL→Schema→运行时渲染器，禁止大模型直出 HTML，页面可控可审计。
5. **写时向量构建**：数据写入即完成本体与向量构建，知识自动积累，无需事后补录。

## 五、可推广性
平台为多租户 SaaS 形态，规则、阈值、审批流、行业术语全部后台配置化，无需改代码即可适配不同行业销售打法；经 MCP 协议可嵌入主流 AI 助手与既有 ERP、审批系统，增量替换、平滑过渡；销售方法论以技能包随平台分发，实施周期短、复制成本低，具备跨行业规模化推广能力。

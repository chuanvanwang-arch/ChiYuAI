# 礼盒订单复盘（2026-08-26）

> 订单概况：礼盒 3000 套 / 成交金额 12.6 万 / 客户已确认满意 + 有复购意向

---

## §0 一句话结论

**这是一单"过程有问题、结果很成功"的订单**：改稿 3 次 + 打样返工 1 次暴露了流程缺口（设计确认与签样未锁死），但最终交付客户满意并带出复购意向。**经验核心：把"改稿"和"签样"变成合同化管理，把满意的客户立刻转入复购动作。**

## §1 订单基本盘

| 项目 | 数据 |
|---|---|
| 产品 | 礼盒 |
| 数量 | 3000 套 |
| 成交金额 | 12.6 万 |

| 复购意向 | 有（**待转化，未锁定**） |

## §2 问题复盘（两条，均为流程问题）

### 问题 1 · 前期客户反复改稿 3 次 → 耽误工期

**根因**：改稿没有设"免费次数 / 超次收费 / 改稿即顺延"的约定，客户无成本地反复改，工期被白白吃掉。

**后果**：工期压缩 → 后续环节都在抢时间，间接也放大了交期风险（与本项目早前原材料延期叠加）。

**判定**：这不是客户难缠的问题，是**我方签约时没设改稿闸门**的问题。

### 问题 2 · 过程打样返工 1 次

**根因**：打样确认环节没有锁死"签样即为准"，返工说明第一次打样后存在信息不一致（可能口头确认、未书面签样）。

**后果**：打样成本重复支出 + 工期再耽误。

**判定**：签样流程缺失 → 返工一次的教训，正是前序画册合同条款第 6 条（签样为准）要解决的问题。

## §3 经验点（可沉淀为 SOP）

| # | 经验 | 动作化 |
|---|---|---|
| 1 | **改稿次数必须进合同**：免费 1-2 次，第 3 次起收费 + 改稿周期相应顺延 | 报价单/合同加《改稿条款》 |
| 2 | **签样即锁**：打样确认必须书面签样（电子扫描 / 微信确认文字），签样后改动一律另计 | 生产单加"签样锁定"栏 |
| 3 | **改稿即顺延**：每次改稿自动推后交期（合同写明），避免改稿吃掉工期后我方背锅 | 交期条款（已有第 2 条顺延条款，本项目用了） |
| 4 | **成本透明记账**：本次返工 1 次的具体成本（材料+机时）单独核算，下次报价作为风险预留系数 | 财务留返工台账 |
| 5 | **客单价 42 元/套是锚点**：同类礼盒后续报价直接可参考，不再盲报 | 报价参考价表更新 |

## §4 后续同类订单注意事项（Checklist）

**签约前：**
1. 规格确认单必签（尺寸/克重/工艺/结构，作合同附件）；
2. 改稿条款写死：**免费次数、超次收费标准、改稿顺延天数**；
3. 签样流程写明：**打样必签样，签样文件为唯一验收基准**；
4. 交期顺延条款（客户原因延期免责）——本项目已验证可用；
5. 预付比例守住（本单 50%，对厂有利）。

**过程中：**
6. 每次改稿留痕（微信文字确认 + 版本号管理），记录"第几次改稿"，到线即提收费；
7. 打样返工台账逐笔记成本；
8. 交期风险预警：工期被改稿吃掉后，第一时间同步客户改交期预期（先预警再补救，别到货期才说）。

**交付后：**
9. 客户满意 → **72 小时内转复购动作**（见 §5），趁热打铁；
10. 把本单的返工成本纳入下次报价的风险系数（经验 4）。

## §5 复购转化动作（本次最值得马上做的）

客户满意度是"易耗资产"，**7 天内不跟进就贬值**。建议 3 步：

1. **3 天内**：微信感谢 + 预告复购
   > "X总，这批礼盒您满意我们就放心了。后面中秋/年节礼盒、常规补货随时找我，老客户给您优先排产和价格照顾。"

2. **7 天内**：给一个"复购钩子"
   > 按本单 42 元/套建立参考价——直接给客户一个"**老客户翻单价**"（比如按量给阶梯价），把"有复购意向"变成"有复购价格"。

3. **30 天内**：推下个节点需求（节日礼盒、新品包装），把礼盒延伸到彩盒/不干胶标签等品类（同厂多品类深挖）。

## 二、提交前必办（内部 checklist）

1. **替换 `[需核实]` 字段**：申请人名称/统一社会信用代码/地址/发明人证件号/联系人——以营业执照与身份证件为准。
2. **发明人确认**：仅列对实质性特点作创造性贡献的自然人（建议王川等），AI/系统不得署名。
3. **附图转黑白**：JPG 版本已直接提供（白底黑线 2040px@300dpi，符合 CNIPA 附图格式），无需再转换；SVG 源文件可由代理机构按需二次编辑。
4. **IPC 分类号**：A 件建议 G06N20/00 或 G06Q30/02；B 件建议 G06N3/00（机器学习记忆）/ G06F16/21（记忆存储检索）/ G06F21/62（租户隔离）（以代理分类为准）。
5. **请求实审 + 费减**：发明须于申请日起 3 年内提实审；小微企业先办结费减备案（实缴约 510 元/件全流程）。
6. **保密审查**：若未来计划 PCT/海外申请，中国申请提交时一并提保密审查请求（免费）。
7. **禁再披露**：申请日前不得在公众号/路演公开"九尺子""红线先于置信""concept_refs"（A 件），以及"双轨记忆/四闸门/judgeWorthiness/七维校验/蒸馏归档/rrfSearch"（B 件）等代码级术语（详见 A/B 披露比对底稿）。

## 四、XML/ZIP 已废弃（2026-09-09 撤回）

曾尝试为每文件生成 XML + 独立 ZIP 供 CPC 客户端导入，但**CPC 客户端校验报「文件包中无 xml 文件或文件包代码与所选文件类型不一致」**——原因：自生成 XML 为自定义根元素（`patent-claims` 等），**不符合《专利电子申请数据标准规范》CEB schema**，客户端拒绝导入。

**结论：XML/ZIP 不可用，回归 MD 文件为权威提交稿。** 相关内容已整体移入 `docs/patents/_deprecated-2026-09-09-xml-zip/` 归档（含 8 个 XML、9 个 ZIP、`manifest.xml`、官方规范包 `ceb-spec/`），不再参与提交。

- ✅ **权威提交稿** = 本目录 8 个 `.md`（A/B 各：权利要求书/说明书/说明书摘要/发明专利请求书）+ `figures/` 下 SVG+JPG 附图。
- 提交路径：登录 `interactive.cponline.cnipa.gov.cn`（案卷号 `10000566468489`），将 `.md` 内容粘贴进对应表单，JPG 附图直接上传。
- 如需标准 CEB XML：请使用官方 **WORD转XML编辑器**（cponline「工具下载」）或代理机构排版后再转化，不要直接用自生成 XML。

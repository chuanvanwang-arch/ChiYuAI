# 说明书摘要

**发明名称**：一种面向智能体运行时的双轨记忆系统构建方法及装置

**摘要**：

本发明公开了一种面向智能体运行时的双轨记忆系统构建方法及装置，属于人工智能多智能体系统领域。该方法建立“日志—笔记”双轨存储：日志区以仅追加方式记录原始记忆，笔记区以唯一键幂等重写记录蒸馏后的常驻知识；写入前经四道闸门（凭证硬拒、显式优先、噪声拒、视界拒）防污染；对日志区周期性蒸馏，达到阈值标记已蒸馏/已归档而不物理删除，使遗忘表现为归档；按分层、主题、实体锚点与租户强制隔离检索，并以哈希余弦+关键词+RRF 混合召回；经校验的客户记忆可提升为租户级经验模板（同租户、仅追加、带决策标识）以防 PII 跨租户泄漏；记忆在智能体运行时经分层上下文注入决策。本发明还以七维框架对记忆做完整性/可问责性校验。本发明解决了智能体长期记忆的污染、遗忘即丢失、租户串扰与注入失控问题，提升了记忆可追溯性与决策质量。

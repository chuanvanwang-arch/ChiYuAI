# A 件·说明书摘要

**发明名称**：一种确定性评分与生成式模型混合的销售决策处理方法及系统

**摘要**：

本发明公开了一种确定性评分与生成式模型混合的销售决策处理方法及系统，解决现有大模型决策不可复现、不可审计、软建议易越过业务硬约束的问题。该方法包括：接收销售业务事件的触发上下文（S1）；调用评分模块执行 N 项确定性规则评分与至多一项生成式模型软评分的混合裁决，确定性评分每次重算结果一致（S2）；按外置权重聚合反算综合置信度（S3）；**在置信度判定之前先执行红线规则硬判定，命中红线或异常处置则无论置信度高低均强制转入人工在环并屏蔽自主放行分支**（S4）；将决策结果、依据、所引先例、裁决时生效的政策版本快照写入决策记录表并分配决策标识，形成可审计追溯链（S5）。本发明兼具确定性可复现与语义理解能力，并以硬规则优先保障治理，适用于多智能体编排下的销售、审批、风控等强合规决策场景。

## 二、提交前必办（内部 checklist，F/G/H 均适用）

1. **替换 `[需核实]` 字段**：申请人名称/统一社会信用代码/地址/发明人证件号/联系人——以营业执照与身份证件为准。
2. **发明人确认**：仅列对实质性特点作创造性贡献的自然人，AI/系统不得署名。
3. **F 件摘要压缩**：`F-K-M-D-管道-说明书摘要.md` 约 340 字，需压缩至 ≤300 字（删除"三段改写"细节展开，保留"三层管道+闭环回流+治理约束"主线）。
4. **附图**：F/G/H 各 3 张附图需由代理或自办转为黑白线条图；SVG 源文件由代理按需二次编辑。
5. **IPC 分类号**（以代理分类为准）：F 件建议 G06N5/00 或 G06N20/00 + G06F16/21 + G06F21/62；G 件建议 G06F16/33（全文检索）+ G06F16/36（本体构建）+ G06F16/21；H 件建议 G06F16/28（数据建模）+ G06F16/30（图数据库）。
6. **请求实审 + 费减**：发明须于申请日起 3 年内提实审；小微企业先办结费减备案（实缴约 510 元/件全流程）。
7. **保密审查**：若未来计划 PCT/海外申请，中国申请提交时一并提保密审查请求（免费）。
8. **禁再披露**：申请日前不得在公众号/路演/参赛材料再公开——F 件"K-M-D/三层管道/闭环回流/复盘改写/审批白名单/审计四问"、G 件"写库即构建/三钩子/contentHash 幂等/双 provider 降级/受控边六映射/backfill/事件总线回流"、H 件"单源双视图/派生视图引擎/DECISION_TIME_BASIS/四源只读聚合/图=寻址·故事=推理"等代码级术语。

# 说明书摘要

**发明名称**：一种基于单一结构化存储派生时间线叙事与关系图谱双视图的构建方法及系统

**摘要**：

本发明公开了一种基于单一结构化存储派生时间线叙事与关系图谱双视图的构建方法及系统，属于人工智能与数据管理领域。该方法维护包含粒子表、关系边表、记忆日志表与决策记录表的单一结构化存储底座；从该底座派生时间线叙事视图——对事件、任务、决策与记忆日志四类数据源进行只读聚合、不落库不复制，按统一时间基准排序生成故事线；从同一底座派生关系图谱视图——以受控关系边为寻址路径执行图结构查询，不另建存储；双视图在上下文装配层融合注入智能体，时间线按正序叙事供推理、图谱按关系寻址供多跳关联；双视图任意元素均携带决策标识可回链决策记录，形成可审计追溯链。本发明解决了同一数据在故事视图与图谱视图间重复存储、口径分裂、时间基准漂移与不可审计的问题，实现单源一次治理、双模复用。

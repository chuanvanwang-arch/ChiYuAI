## 三、线索分级：B 级（温线索 / 培育型）

**分级标准**
- **A 级（热）**：需求明确 + 预算充足 + 有决策权 + 时间紧 → 立即推进商务
- **B 级（温）**：有需求但关键要素（预算 / 决策人）缺失，需持续培育 → 本线索
- **C 级（冷）**：需求模糊、无预算、无时间线 → 低优先级触达

**本线索判为 B 级理由**
1. 强需求（高故障率真实痛点）+ 清晰时间窗，价值潜力明确；
2. 但预算未定、决策人/采购流程未知，尚不能进入商务报价；
3. 客户明确「暂不上门、先微信」= 主动设置低温沟通边界，需以内容信任换推进。

**升级 A 级的触发条件**：预算区间明确 + 确认决策人/流程 + 客户同意进入方案/报价阶段。

## 四、下次跟进要点（行动指南）

1. **尊重沟通边界**：严格执行「暂不上门、微信为主」，用轻量、高频、有价值的触达建立专业信任，切忌冒然约访。
2. **打透核心诉求——售后响应速度**：
   - 准备差异化素材：响应时效承诺（如 X 小时响应 / X 小时到场）、本地服务网点与工程师、备件库存、远程诊断能力；
   - 用「老设备故障率 → 停机损失」做价值量化，帮客户内部立项争取预算。
3. **引导预算区间**：提供按产能 / 盒型 / 自动化程度的选型框架，让客户自行锚定预算档位，而非直接报价。
4. **设置下半年节奏节点**：Q3 末探明预算与决策链 → Q4 推进方案/试用/报价；可在 CRM 建提醒。
5. **内容培育**：定期推送故障预警、维保 tips、同行业改造案例（微信可接收形式），维持存在感与专业度。

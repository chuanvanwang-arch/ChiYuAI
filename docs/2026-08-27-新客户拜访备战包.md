# 新客户拜访备战包（2026-08-27）

> 用途：今日拜访新客户前快速准备 + 拜访后回写 CRM
> 配套可复用：`docs/2026-08-26-礼品盒包装开发话术.md`（微信/邮件版）、`docs/2026-08-26-彩盒报价单-初稿.md`（报价参考）、`docs/2026-08-26-印刷需求确认单-画册.md`（需求确认模板）

---

## §0 一句话行动

拜访前 30 分钟：定目标（要什么承诺）→ 带对物料 → 记住三条话术；回访后 10 分钟：把"客户是谁/聊了什么/下一步"回写 CRM，让明天有据可循。

## §1 拜访前：先想清楚 4 件事

| # | 问题 | 自检 |
|---|---|---|
| 1 | **这个客户是谁** | 行业/规模/决策人/我们厂能做什么（印刷包装：礼盒/彩盒/画册/不干胶/说明书…） |
| 2 | **为什么是今天** | 新需求线索？转介绍？区域顺路首次触达？ |
| 3 | **这次要什么结果** | 拿需求信息 / 要报价机会 / 约下次带样 / 直接敲单 —— 定一个主目标 + 一个备选 |
| 4 | **预算与决策链** | 对方谁是拍板人、谁是使用者；预算是集中采购还是单点分散 |

## §2 必带物料清单（按拜访目的勾选）

| 物料 | 用途 | 来源 |
|---|---|---|
| 样册/样盒（礼盒、彩盒、烫金模切样品） | 让客户摸到质感——**印刷销售第一武器** | 厂里样品间 |
| 厂介绍（产能/设备/起订量） | 建立"能做且靠谱"认知 | 现有资料 |
| 名片 | 基础 | — |
| 报价单样例（彩盒 5000 只参考） | 客户模糊询价时给锚点，不现场拍脑袋 | `docs/2026-08-26-彩盒报价单-初稿.md` |
| 需求确认单（画册版可套用） | 现场把模糊需求变成可执行参数 | `docs/2026-08-26-印刷需求确认单-画册.md` |
| 开发话术（微信/邮件版） | 拜访后 24h 内跟进发送 | `docs/2026-08-26-礼品盒包装开发话术.md` |

## §3 拜访中：现场要问清的 6 个问题（把需求问成"可报价"）

1. **做什么**：产品类型（礼盒/彩盒/画册/说明书/不干胶…）？
2. **量多少**：起订量预计多少？有无年框/返单（量大谈价空间大）？
3. **规格工艺**：尺寸、纸张克重、印刷方式（四色/专色）、后道（覆膜/烫金/模切/UV/装订）？
4. **时效**：交期要求多久（决定报价口径与排产）？
5. **钱**：含税？发票类型？付款习惯（预付比例/账期）？
6. **决策链**：谁确认需求、谁确认价格、谁最终拍板？

> 现场拿不准的，用确认单记下来，回来发《需求确认单》给客户逐项确认——**把口头需求变成书面参数，是防扯皮的第一道闸**。

## §4 拜访后：24 小时内固定动作

1. **当天回写 CRM**：新客户建档（公司名/联系人/行业/区域/工商抬头）+ 记录拜访要点（聊了什么/客户痛点/下一步）→ 走写通道（决策第 0 闸）；
2. **24h 内发跟进**：微信简短版或邮件正式版（`2026-08-26-礼品盒包装开发话术.md`），明确报价机会；
3. **有具体需求** → 发《需求确认单》 → 按需求出报价单 → 走报价审批（两级：销售经理→总经理）；
4. **预约下次**：带样/带报价回访，别让热度冷掉。

## §5 拜访后 CRM 回写清单（给 AI / 业务填）

```
客户公司名：
联系人/电话：
行业/规模/区域：
主营业务（和我们相关的印刷品）：
今日拜访要点 / 客户痛点：
客户表达的需求（产品/数量/规格/交期）：
下一步（报价/寄样/约下次/待确认）：
```

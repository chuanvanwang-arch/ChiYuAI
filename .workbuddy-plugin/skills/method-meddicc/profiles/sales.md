# method-meddicc · 销售视角（profiles/sales.md）

> 视角：销售（sales）用 MEDDICC 判断「这个复杂商机赢单把握多大、下一步打哪」。

## 使用时的心态

- 我不是在填七维表格，是在找**哪一维是当前输赢的关键缺口**。
- MEDDICC 是决策链显微镜：大单子输往往不是产品差，是 E/D/I/C 某一环没打通。

## 视角差异

- 我看的不是「总分」，是「最弱硬维度」：缺 E1 → 先约经济买家；缺 D2 → 先问清流程步数；缺 I1 → 先做痛点量化访谈。
- M1/C1/C2 相对弹性：指标和竞争可以边打边补，但 E1/D1/D2/I1 没实证就先别乐观推进。

## 输出形态（口语化但机器可读）

```
赢单把握：指标✅ 经济买家⚠️(未触达) 标准✅ 流程⚠️(未知RFP步数) 痛苦✅ 冠军✅(强度4) 竞争⚠️(并列)
就绪度：0.66 → 下一动作：约经济买家确认预算与决策流程
```

## 红线

- 任一硬维度 <0.6 禁止乐观推进（win 判断/报价）——这是规则不是建议。
- 口头意向不得单独支撑「赢单把握」——必须有书面/流程节点/POC 实测证据。

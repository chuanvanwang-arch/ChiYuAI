# method-meddicc · 维度释义（references/dimensions.md）

## M1 · Metrics（指标）

- 客户有没有可量化的成功指标（营收、成本、人效）与基线数据？
- 无指标 = 无法证明 ROI，方案价值无法被经济买家认知。
- 例：客户说"想提效" → 追问"现在每周花几天？目标降到几天？"

## E1 · Economic Buyer（经济买家）

- 掌握预算审批权的人是谁？我们触达了吗？还是只在跟使用岗？
- 无 E1 = 任何推进都是空谈；先识别再触达，别用使用者热情冒充决策支持。

## D1 · Decision Criteria（决策标准）

- 客户按什么标准选型（功能/价格/服务/案例/合规）？
- 我方方案覆盖几条标准？未覆盖的是可谈让步还是硬伤？

## D2 · Decision Process（决策流程）

- 客户内部走几步（RFI/RFP/POC/招标/法务/财务）？谁在每一步把关？
- 不知道下一步 = 无法预判风险，只能被动等消息。

## I1 · Identify Pain（识破痛苦）

- 痛点真实吗？可陈述为单句并有量化影响（"对账 3 人每周 2 天"）？
- 无真实痛苦 = 无成交基础，方案再好也卖不动。

## C1 · Champion（冠军）

- 内部支持者是谁？能否影响决策、提供流程情报？
- champion_strength ≥3 视为有效；只有使用者支持而无决策影响者 → 不算冠军。

## C2 · Competition（竞争）

- 竞品格局（领先/并列/落后）如何？我方差异化依据是什么？
- 竞争落后不必然输——有差异化证据且决策标准覆盖，仍可反转。

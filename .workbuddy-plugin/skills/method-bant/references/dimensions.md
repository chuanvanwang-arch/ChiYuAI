# method-bant · 维度释义（references/dimensions.md）

## B · Budget（预算）

- 预算是否明确？金额在不在平台可售产品价格带内？
- 有没有预算批复/预算线？是自有预算还是总部配额？
- 反例：客户说"钱不是问题"但无预算号 → 仍视为未满足（无法核验即无证据）。

## A · Authority（决策权限）

- 对接人是决策人（CEO/VP/采购负责人）还是使用者/秘书？
- 决策链多长？除对接人外还有谁拍板（CTO/财务/合规）？
- 使用 `champion_strength`（内部支持者强弱）佐证：≥3 视为有内部推动力。

## N · Need（需求）

- 痛点是否真实紧迫、可陈述为单句（"我们的对账要 3 个人力每周 2 天"）？
- 有无替代方案已在竞争（自研/竞品/外包）？替代方案是加分异议源，不减分资质。

## T · Timeline（时间线）

- 客户计划何时买？有明确季度/月份/事件触发（如财报季前）？
- 无时间窗 = 需求可能不紧迫 → T 弱但非硬维度（B/A/N 才是硬维度）。

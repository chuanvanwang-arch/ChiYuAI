# method-opportunity-matrix · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）用机会矩阵看**整个团队的商机组合**，决定团队资源与激励方向。

## 使用时的心态

- 我看的不是单条商机，是**组合结构**：几条主攻、几条收割、几条培育、几条该淘汰。
- 矩阵是资源分配依据：把最能打的销售/售前资源压到 PRIMARY 象限。

## 视角差异

- 看象限分布与金额集中度：PRIMARY 总金额占管线多少？PARK 里有没有该清掉的长期僵尸单？
- 看缺口模式：普遍 NURTURE（可行性不足）→ 团队缺决策链打法（上 MEDDICC 训练）；普遍 PARK → 商机准入标准要收紧（上 BANT 预习）。

## 输出形态（口语化但机器可读）

```
团队组合：20 条/5200 万 → PRIMARY 6 条/2800 万（主攻）/ HARVEST 5 条/900 万（快取）/ NURTURE 6 条/1100 万（培育）/ PARK 3 条/400 万（暂缓清理）
本月动作：PRIMARY 配售前资源；PARK 3 条通知 owner 补价值证据或放弃
```

## 红线

- PARK 不得占用主攻资源——暂缓就是暂缓，别让僵尸单吃掉团队工时。
- 季度校准：至少一次用矩阵重排整个商机池，防止管线虚胖。

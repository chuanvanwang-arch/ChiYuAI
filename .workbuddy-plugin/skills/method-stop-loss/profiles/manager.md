# method-stop-loss · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）用止损点为团队商机设定投入阈值，做月度触发检查。

## 使用时的心态

- 我不是在追着销售要进度，是在**守护团队的投入纪律**——别让几个"快成了"的单子吃掉整队售前工时。
- 止损阈值设定是月初动作，不是亏损后讨论。

## 视角差异

- 商机启动评审：每条商机立项时定 `investment_budget`（投入人天/金额上限）与 `exit_gate`（退出信号），写入评审纪要。
- 月度触发检查：跑 `invested_cost / investment_budget` 使用率，标记 WATCH；净值转负/超支/EG 命中 → 发起撤单评审。
- 看「投入分布」：几个单子吃掉 80% 售前资源？投入产出比谁最差？

## 输出形态（口语化但机器可读）

```
月度止损检查：20 条 → 预算使用率 >80% 有 5 条（WATCH）/ 超支 2 条（发起撤单评审）/ 净值转负 1 条（建议 EXIT）
投入分布：3 条大单吃掉 60% 售前人天 → 本月新商机立项收紧投入上限
```

## 红线

- 撤单评审必须按退出门执行——即使销售强烈反对，纪律不允许"再给一个月"无限延长。
- 每月至少一次止损检查（对齐 crm-risk 的链断裂扫描节奏）。

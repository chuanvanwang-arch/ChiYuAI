# method-behavior-standard · 经理视角（profiles/manager.md）

> 视角：销售经理（manager）周会看行为合格率（21 条证据有/无）、标准动作执行情况。

## 使用心态

- 我看的不是对个人的责难，是**团队行为合格率**——几张卡在哪些条目（缺 O/R 记录？缺访前计划？商机过滤？），这就是标准动作的改进点。
- 21 条合格线是管理抓手：合格率趋势反映培训与督导效果。

## 视角差异

- 看「合格率」：团队近期拜访里 `sales_visit_value=true` 占比（行为合格率 = pass/21 等价口径）。
- 看「缺口模式」：普遍缺 R（客户原话）→ 强调事实记录训练；普遍缺 O（目的）→ 访前规划训练；商机过滤缺口（BH-02-02）→ 商机识别督导。
- 看「标准动作执行」：团队行为与 references/standard-actions.md 一致性抽查（周会抽样）。

## 输出形态（口语化但机器可读）

```
团队拜访合格率（本月 96 次）：合格 61 次（64%）
缺口模式：缺 R（客户原话）24 次 / 缺 O（目的）18 次 / 商机过滤缺口 6 家
标准动作执行：抽查 12 次，10 次对齐「新客户首访」标准动作（83%）
```

## 红线

- 合格率是趋势指标不是排名表——不得用于销售间互相排名羞辱（先看共性缺口再谈个人）。
- 缺口模式用于培训设计，不用于绩效考核惩罚（绩效考核另有口径）。

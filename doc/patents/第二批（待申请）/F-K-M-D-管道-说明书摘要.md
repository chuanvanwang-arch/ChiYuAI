# 说明书摘要

**发明名称**：一种多智能体系统的知识-记忆-决策三层闭环管道构建方法及系统

**摘要**：

本发明公开了一种多智能体系统的知识-记忆-决策三层闭环管道构建方法及系统，属于人工智能多智能体系统领域。该方法建立知识层、记忆层与决策层三层纵向管道：知识层以配置化方式存储领域本体、供给操作集、阈值与策略版本并在决策装配时实时注入；记忆层以仅追加方式存储原始事件与决策历史、以幂等重写方式存储蒸馏后常驻记忆；决策层执行确定性评分与生成式模型软评分混合裁决并落库。核心在于闭环回流：决策复盘事件触发三段改写——复盘产物中的知识更新经可处方键白名单校验映射为待审批配置处方，后见之明以仅追加方式改写记忆而不覆盖原始轨迹，裁决-复盘偏差超阈值时生成须人工确认的自适应建议，三段改写结果回流至知识层与记忆层供后续决策消费，形成"知识-记忆-决策-回流"的纵向闭环。本发明解决了智能体决策系统不学习、知识记忆决策相互割裂与回流缺乏治理的问题，实现决策系统随运行自动生长且回流可审计、不越租户作用域。

## 五、答辩要点备忘（30% 方案答辩用）

| 评审可能追问 | 建议回答口径 |
| :-- | :-- |
| 三维置信度的权重怎么定？ | 三项均为可复算的确定性评分打底（8 项确定性 + 1 项模型评估），权重按研判域配置，公开可查、可审计，不写死在代码里。 |
| 博弈对抗怎么保证不会无限辩论？ | 仲裁有轮次上限与终止条件（证据耗尽 / 达到置信度阈值 / 触发人工仲裁），终止后必出结论或明确报"缺依据"。 |
| 因果校验是否真的做到了因果推断？ | 严格要求下不算完整因果推断——我们做的是**因果可疑性筛查**（时序、反事实、混杂），本阶段不接入专用因果推断库，这一项我们不做过度声称。 |
| 少数意见留档会不会让结论不明确？ | 主流结论始终是唯一对外输出，分歧作为附件与推理树的一个分支保留，复核人可展开查看，不干扰决策口径。 |
| 人工干预后如何保证审计完整？ | 干预为软标记 + 全量留痕：原始证据不删除，修改前后两版结论与置信度同时入审计哈希链，可校验不可篡改。 |

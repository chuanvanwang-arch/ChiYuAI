# 交付物清单

## 1. 代码包
- `src/chiyu_group/`（完整算法包：ingest/features/memory/decision/evaluate/serving/main CLI）
- `pyproject.toml`（包元数据 + pytest 配置）
- `requirements-common.txt / requirements-cpu.txt / requirements-cuda.txt / requirements-ascend.txt`（四通道依赖锁定）

## 2. 容器化
- `docker/Dockerfile.base`（非信创一/信创一，无 GPU，内嵌权重）
- `docker/Dockerfile.cuda`（非信创二，A100）
- `docker/Dockerfile.ascend`（信创二，昇腾 910B）
- `docker/docker-compose.yml`（三 profile：base/cuda/ascend）

## 3. 数据
- `data/sample/sample.csv`（官方样例 43 条，内置）
- `data/gazetteer/`（区划码表/别名表，离线）
- `data/real/`（真实挂载通道，评测现场由主办方覆盖挂载）
- `data/uploaded/`（API 上传通道）

## 4. 模型权重
- `models/bge-large-zh-v1.5.onnx`（随包携带；缺失时 InferBackend 自动降级哈希 384 维，链路不中断）

## 5. 文档
- `README.md`（部署/运行/评测/容器/三通道说明）
- 概要方案（DEMO环境-概要方案.md）
- 详细方案（DEMO环境-详细方案.md）
- 评分指标满足性（评分指标满足性与模型构建方案.md）
- 性能分析报告（docs/性能分析报告.md）

## 6. 输出产物
- `output/predictions.csv`（`order_id,gid` 格式）
- `output/eval_report.md / eval_report.json`（四指标评测报告）

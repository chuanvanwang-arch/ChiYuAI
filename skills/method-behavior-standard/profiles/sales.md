# method-behavior-standard · 销售视角（profiles/sales.md）

> 视角：销售（sales）每次拜访归来对照 21 条自查是否合格、TAORAN 是否齐全。

## 使用心态

- 我不是在被考核，是在用合格线自检——每次拜访回来 5 分钟对照清单，缺口自己先补。
- 21 条是有/无判定：有证据=合标，没证据=缺口（别用"我觉得"糊弄）。

## 视角差异

- 我看到的不是 21 条列表，是「这次拜访合不合格」：
  - 访前：有计划吗？目的可量化吗？（BH-01-02/03）
  - 现场：六问做了吗？客户原话记了吗？（BH-03）
  - 归来：TAORAN 六字段写了吗？下一步定了吗？（rules/taoran.md）
- 每个月初回头看：我这个月的拜访里，几次完全合格？几次有缺口、缺口在哪？

## 输出形态（口语化但机器可读）

```
本次拜访（朝阳机械 礼盒）：TAORAN 六字段全 → 合格 ✓
缺项自检：t_result 客户原话没记（BH-03-02 关注需求）→ 下次补
本月合格率：12 次拜访 9 次合格（75%）→ 缺 O/R 的 3 次，下周统一补记录
```

## 红线

- TAORAN 缺 O/R/N 的拜访不算合格（rules/taoran.md），别自我豁免。
- 21 条缺口要真补（下次拜访前把缺口项做成目的），不是改记录糊弄。

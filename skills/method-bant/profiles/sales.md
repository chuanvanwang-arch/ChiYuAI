# method-bant · 销售视角（profiles/sales.md）

> 视角：销售（sales）用 BANT 判断「这个商机现在该不该继续投入」。

## 使用时的心态

- 我不是在填表，是在决定「下一小时投入在哪」。
- BANT 是资质门，不是评分秀——任一硬维度（B/A/N）没证据 = 先补证据再推进，别用话术糊弄自己。

## 视角差异

- 我看到的不是「四维打分」，是「下一动作」：缺预算 → 先要预算号；缺决策人 → 先约决策人；缺需求 → 先做痛点访谈；缺时间线 → 先问采购计划。
- 时间线弱不阻断（T 非硬维度），但缺时间线的单子优先排在「待观望」而非「现在打」。

## 输出形态（口语化但机器可读）

```
资质：预算✅ 权限⚠️(对接人是使用岗，未触决策人) 需求✅ 时间线⚠️(无明确窗)
就绪度：0.62 → 下一动作：约采购负责人聊预算与决策链
```

## 红线

- 任一硬维度 <0.6 禁止 `crm-deal-advance`（阶段推进）——这是规则不是建议。
- 口头意向不得单独支撑「推进」——必须有书面/实测证据。

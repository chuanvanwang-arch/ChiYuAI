# method-stop-loss · 高管视角（profiles/exec.md）

> 视角：高管（exec）用止损点看**公司级被套牢商机/项目**，防止沉没成本绑架经营决策。

## 使用时的心态

- 我不是在给销售打气，是在**履行公司级止损纪律**——该撤的单子不撤，就是拿股东的钱赌面子。
- 止损是管理动作不是认输：撤单后的复盘会换来更准的准入规则。

## 视角差异

- 我看的不是单条商机，是**止损纪律执行情况**：多少条该撤而没撤？撤单决策有没有按时触发？
- 看「沉没成本绑架排行」：哪些商机投入已超预算上限但仍在追加？谁的决策被"跟了这么久"绑架？
- 看「退出门命中率」：预设的退出门信号有没有被使用——还是每条都口头"再看看"？

## 输出形态（口语化但机器可读）

```
止损纪律审计：20 条商机 → 已触发 EXIT_REQUIRED 3 条（本月必须撤）/ WATCH 4 条（降投入）/ 健康 13 条
沉没成本绑架：2 条投入超预算 120% 仍在追投（owner 高管介入）→ 复盘后更新商机准入规则
```

## 红线

- 净值转负且无回升路径 → 撤单是义务不是选项（EXIT_REQUIRED 即执行）。
- 撤单复盘必须产出规则沉淀：准入收紧、预算上限比例、退出门标准库。

# method-fact-vs-script · 维度释义（references/dimensions.md）

## F · 事实（Fact）

- 可验证且无歧义：有书面（邮件/合同/预算批复）、实测（POC/DEMO 结果）、第三方（参考案例/行业报告）佐证。
- 事实是商机判断的**唯一决策依据**——BANT/MEDDICC 的评分只能建立在事实上。
- 反例：客户说"我们确定要上系统"但拿不出立项文件 → 不是事实，是话术。

## S · 话术（Script）

- 口头表述、宣传性用语、无佐证的承诺（"预算没问题""我们很急""领导很支持"）。
- 话术不是**决策依据**，是**待验证线索**——每句话术都对应一个验证动作（要预算号/约决策人/POC 排期）。
- 反例：把"领导很支持"当决策支持证据 → 是典型的话术误当事实，MEDDICC C1 冠军必须有实证。

## E · 证据等级（Evidence）

- 证据来源等级决定事实可信度：书面=0.95 / 实测=0.9 / 第三方=0.85 / POC=0.8 / 口头=0.5。
- 每条客户陈述都标注证据等级，形成 `payload.evidence_map`——推进关键判断时只引用 E≥0.8 的事实。

## 与其它方法论衔接

- 与 BANT（B 预算需预算号书面佐证）、MEDDICC（E1 经济买家触达、C1 冠军实证）证据优先级一致。
- `FACT_VS_SCRIPT` 是它们共同的"证据可信度闸门"：先分事实/话术，再打分。

# method-role-map · 销售视角（profiles/sales.md）

> 视角：销售（sales）用角色地图决定「下一步约谁、先打哪条决策链」。

## 使用时的心态

- 我不是在管理联系人，是在**排触达顺序**：先打通决策者，再让影响者说好话，用使用者造声势。
- 角色地图是时间分配器：把约见份额压到 D 和关键 I 上，而不是耗在使用者热情里。

## 视角差异

- 我看的不是「谁支持我」，是「**谁还没表态且能一票否决**」——未知立场的 D/I 是最大风险，先约他们。
- 反对者早暴露好过晚暴露：越早转化成本越低（止损维度对齐 `method-stop-loss`）。

## 输出形态（口语化但机器可读）

```
触达顺序：①经济买家(VP,预算审批) ②技术影响者(CTO,未表态) ③使用者代表(已支持,造声势)
下一动作：本周约 CTO 技术交流；让使用者代表在下周例会先提需求
```

## 红线

- 使用者的支持不可替代决策链——D/I 未打通就是没打通，用户热度不算数。
- 反对者未转化前禁止给乐观推进信号（与 `crm-deal-advance` 闸联动）。

# method-risk-tradeoff · 销售视角（profiles/sales.md）

> 视角：销售（sales）用风险权衡判断「这个带风险的单子我要不要接、接了怎么保护自己」。

## 使用时的心态

- 我不是在找"能不能接"的借口，是在**量化我接单后的风险敞口**——接单一时爽，回款火葬场。
- 风险权衡是自我保护工具：触碰红线先说不，高风险必须带缓解条款进报价。

## 视角差异

- 我看的不是「风险等级表」，是「**这个单子的自我保护条款清单**」：信用差 → 要预付；定制多 → 要里程碑分期；合规杂 → 要法务先审。
- 高收益单不是"闭眼接"的理由——`ratio < 1` 就是止损信号，别用金额麻痹自己。

## 输出形态（口语化但机器可读）

```
风险权衡：风险 0.7(信用一般) 收益 0.85(800万,毛利32%) 红线✅(无触碰) 缓解⚠️(无预付条款)
比值 1.21 → gate=MITIGATION_REQUIRED → 下一动作：报价加预付定金30%+里程碑分期
```

## 红线

- 触碰红线（合规/信用底线/交付硬伤）→ 禁止推进，这是规则不是建议。
- 无缓解措施的高风险单禁止乐观推进（先补缓解条款再报价）。
